# Jungle Vault : Emojicoin

A premier emojicoin staking platform built on Aptos blockchain, enabling users to stake their emojicoin tokens and earn rewards through innovative vault mechanisms.

## Features

- **Emojicoin Staking**: Stake your favorite emojicoin tokens in secure vaults
- **Dynamic Pool Creation**: Create custom staking pools with flexible parameters
- **NFT Boosts**: Enhance your rewards with special NFT multipliers
- **Milestone Rewards**: Unlock bonuses as you reach staking milestones
- **Real-time Analytics**: Track your performance with detailed dashboards
- **Cross-chain Compatible**: Built on Aptos for fast, secure transactions

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <repository-url>

# Navigate to the project directory
cd jungle-vault

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Building for Production

```bash
# Build the project
npm run build

# Preview the build
npm run preview
```

## Technology Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: Tailwind CSS with custom design system
- **UI Components**: Shadcn/ui component library
- **Build Tool**: Vite for fast development and builds
- **Blockchain**: Aptos integration for emojicoin interactions
- **State Management**: React Context API
- **Routing**: React Router v6

## Project Structure

```
src/
├── components/          # Reusable UI components
├── pages/              # Route components
├── hooks/              # Custom React hooks
├── contexts/           # React Context providers
├── types/              # TypeScript type definitions
├── services/           # API and blockchain services
├── utils/              # Utility functions
└── data/               # Mock data and constants
```
